## عزل مساحات الزوار

سبعة اختبارات خادم تغطي ثبات المساحة خلال الزيارة وتغييرها للزائر الجديد، ورفض تبويب قديم، وعدم اعتماد معرّف ضيف من الرابط، وعزل التصاميم والقوائم، ومنع كاش HTML المشترك، وخدمة صور الكتالوج دون جلسة أو Cookie. فحص التخزين المحلي يغطي فصل هويتين داخل مخزن واحد وتجاهل البيانات القديمة والمخالفة والتالفة والمنتهية.

نجح Chromium وWebKit في فصل زائرين مجهولين، وبدء مساحة جديدة داخل المتصفح نفسه مع بقاء البيانات القديمة في تخزينه، ورفض تصميم وصورة الزائر السابق، ومنع انتقال كتابة التبويب القديم، واستعادة تغييرات صاحب الزيارة عند فشل الحفظ. لا تظهر رسالة مسودة معلقة عند فتح تصميم جديد. الفصل بين أشخاص على المتصفح نفسه يحتاج زر «مساحة زائر جديدة»؛ لا يُدّعى اكتشاف تغيّر الشخص تلقائياً.

## قياسات العينة

- البطاقة/الستيكر التجريبي: `85.60 × 53.98 mm`.
- نزف: `2 mm`، وفق مثال هندسي لا اعتماد مطبعة.
- صفحة PDF: `89.60 × 57.98 mm`، وTrimBox مطابق للستيكر.
- PNG: `1058 × 685 px`، مع بيانات كثافة تقارب 300 PPI بعد التقريب.
- معاينة الجهة الشفافة `1011 × 638 px` وكل قيم Alpha فيها صفر؛ ليست رسماً أبيض.
- مسارات قص Vector منفصلة، ولا شعار متجر أو شبكة شفافية أو تقشير أو إرشادات في الرسم المطبوع.

## ما يحتاج بيانات أو تحققاً خارجياً

1. **اعتماد المطبعة:** لم ينفذ هذا الفحص عينة مادية. القوالب التي ينشئها Seeder تجريبية؛ أي اعتماد يدخله المالك يحتاج تجربة مطبعة مستقلة. تُراجع الأبعاد والفتحات والاستدارة والنزف والخامة والقص باتجاه 100% دون Fit to Page.
2. **الخامات والمعدات:** لم يُثبت توافق NFC/ATM أو خصائص الماء/الإزالة، ولم تُختبر آلة قص معينة. لا توجد هذه الوعود في المتجر.
3. **إعداد المالك:** أسعار المنتجات والتخصيص، الخامات والتشطيبات المتاحة، أجور التوصيل ومدده وتغطيته، التواصل وInstagram وWhatsApp والسياسات.
4. **الخادم العام:** نطاق وTLS وDNS وPHP-FPM وموارد عامل Chromium ونسخ خارجية. لا يوجد نشر عام أو بيانات استضافة مقدمة.
5. **المتصفحات الفعلية:** فُحص Chromium وWebKit آلياً. ما زال يلزم فحص iPhone/Android فعليين ومتصفح Instagram المدمج وإدارة الملفات من معرض الهاتف. لا يُدّعى أن محاكاة WebKit تساوي اعتماد كل إصدارات Safari على أجهزة فعلية.
6. **تكاملات اختيارية:** بوابة دفع إلكتروني وSMTP وإشعارات WhatsApp وInstagram feed والتحليلات لم تُربط. المعروض للدفع هو COD فقط، ولا تجمع بيانات بطاقة دفع.
7. **CMYK/ICC/PDF/X والحبر الأبيض/الانعكاس:** غير مفعّلة في المحرك الحالي. تحتاج محركاً وإعداد مطبعة واختباراً فعلياً. الناتج sRGB PDF/PNG وSVG مستقل للقص.

HEIC لا يُحوّل تلقائياً في النسخة الحالية؛ تظهر إرشادات واضحة لتصديره كـJPEG. القوالب تُدار بهندسة JSON محققة، ولا تُقبل ملفات SVG تنفيذية من الزبون. النظام لا يوفر شيت تجميع تلقائياً أو محرراً للموظف يستبدل تصميم طلب معتمد؛ كل طلب يثبت نسخة مستقلة.

## إعادة تشغيل الفحوص

في بيئة الفحص ثبّت اعتماديات التطوير بـ`composer install` دون `--no-dev`، مع اعتماديات npm والمتصفحات اللازمة.

```sh
php artisan test
npm run test:render
```

على هذا الجهاز توجد قاعدة `sticker_fight_qa` وبيئة `.env.qa` منفصلتان. لتشغيل اختبارات المتصفح:

```sh
php artisan serve --env=qa --host=127.0.0.1 --port=8001
node scripts/browser-test.mjs
node scripts/editor-regression-test.mjs
node scripts/ready-product-test.mjs
node scripts/theme-test.mjs
node scripts/preview-test.mjs
```

اختبار المتصفح يحتاج حسابات QA التي يولدها `scripts/qa-seed.php` داخل `.runtime/qa-users.json`، ويشغل عامل Queue مؤقتاً. لا تشغّل Seeder الاختبار على قاعدة الإنتاج؛ السكربت يرفض اسماً غير `sticker_fight_qa`. على جهاز آخر جهّز قاعدة وبيئة QA خاصة بك أولاً؛ سكربت إنشاء قاعدة QA المرفق مرتبط بمسارات MySQL المحلية لهذا الجهاز.

ملخص المتصفح والصور في `.runtime/` خاص بالتطوير. حزمة التسليم لا تشمل هذه البيانات أو كلمات المرور أو `.env`. الصور العامة للواجهة في `deliverables/` لا تعرض بيانات عميل أو أسعاراً مختلقة.
